# 📝 Linguagens de Marcação - XML

Este repositório contém a resolução de uma atividade da Unidade Curricular **Linguagens de Marcação**, com foco na linguagem **XML (eXtensible Markup Language)**. O objetivo do trabalho foi compreender os fundamentos da linguagem XML por meio de pesquisa e da correção de documentos, identificando e aplicando corretamente suas regras de sintaxe e estrutura.

---

## 📌 Pesquisa sobre XML

Foi realizada uma pesquisa sobre a linguagem XML, abordando seus conceitos, características, estrutura, vantagens e principais aplicações. Esse estudo permitiu compreender como o XML é utilizado para organizar e representar informações de forma estruturada, facilitando a troca de dados entre diferentes sistemas.

---

## 📌 Correção de Códigos XML

A atividade consistiu na análise de códigos XML contendo erros de sintaxe e estrutura. Cada documento foi corrigido de acordo com as regras da linguagem, garantindo que estivesse bem formado e pudesse ser interpretado corretamente.

---

## 💡 Conceitos Utilizados

- Linguagens de Marcação
- XML (eXtensible Markup Language)
- Estrutura hierárquica de elementos
- Tags de abertura e fechamento
- Elemento raiz
- Atributos
- Sintaxe XML
- Documentos bem formados
- Organização e representação de dados

---

## 🎯 Objetivo do Projeto

Desenvolver a compreensão sobre a linguagem XML, aplicando seus conceitos na identificação e correção de erros de sintaxe e estrutura. Além disso, compreender a importância das linguagens de marcação na organização de dados e na comunicação entre diferentes aplicações.
